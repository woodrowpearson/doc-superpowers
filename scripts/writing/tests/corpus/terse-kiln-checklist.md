# Kiln firing checklist

Run this list before every glaze firing. Tick each box when it is done.

- [ ] Sweep the shelves and wipe each post with a damp sponge.
- [ ] Load the heavy bowls on the lower shelf, keep a thumb of space between every pair of pieces, and put the small cups on the top shelf beside the peep hole where the cone pack sits in plain view of the person on duty.
- [ ] Set the controller to program 3 (slow glaze). Check the first segment climbs no faster than sixty degrees an hour. Note the time. Ring the studio lead if it runs faster than that.
- Mark the cone pack with the date.

| Cone | Peak |
|------|------|
| 06 | 999 |

Hold the peak for twenty minutes after the witness cone bends, then switch the controller off and leave the kiln closed until it reads below one hundred degrees, which usually takes the whole of the following day and part of the night.

The shelf set TK12 was cracked in the last firing.
