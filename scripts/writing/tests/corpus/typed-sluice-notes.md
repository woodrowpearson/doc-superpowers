# Sluice gate notes

These notes sit in a guides folder, and the doc-index types them as a plan, so the lint reads them in the terse register.

Open the lower gate a quarter turn at a time, wait for the water in the chamber to settle between each turn, and write the level in the book before and after so the next person can see what changed.

- Grease the spindle. Wipe the housing. Log the date.
- Close the upper gate last.
